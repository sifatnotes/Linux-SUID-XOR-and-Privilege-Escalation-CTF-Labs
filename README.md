# Linux SUID, XOR, and Privilege Escalation CTF Labs

A searchable collection of Learn SecByte cybersecurity labs focused on Linux SUID permissions, privilege escalation, shell security, XOR cryptography, encoded challenges, and Earth-themed CTF exercises.

This repository helps cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners discover hands-on exercises for Linux security, access-control investigation, cryptographic problem-solving, and shell-related security concepts.

## Introduction

Capture the Flag (CTF) challenges provide a practical way to explore cybersecurity concepts in controlled environments. This collection organizes the supplied labs into categories so learners can find relevant exercises and follow a structured learning path.

## Categories

- **Linux access controls:** SUID permissions and privilege escalation awareness.
- **Shell security:** Shell troubleshooting and shell-related challenges.
- **Cryptography:** XOR operations, encoded data, and cipher investigation.
- **CTF file analysis:** Searching for and analyzing challenge files.
- **Network security concepts:** Reverse-shell behavior and defensive investigation.

## Learning Path

1. Begin with SUID Sleuth to understand Linux permissions and access-control risks.
2. Explore the Earth privilege escalation and shell rescue challenges.
3. Practice reasoning through XOR and encoded-data puzzles.
4. Study shell-related challenges in an isolated lab.
5. Review reverse-shell concepts from both an attacker-behavior and defensive-monitoring perspective.

Adjust the sequence to match the prerequisites and difficulty specified by each lab.

## How to Use the Labs

1. Select a lab from the searchable index.
2. Read its official instructions and learning objectives.
3. Complete the exercise in an isolated, authorized environment.
4. Document commands, observations, and findings.
5. Record relevant mitigations, secure configurations, and lessons learned.
